# Adventure Works - Cleaning Data With Pyhton
## Project Overview
This project focuses on cleaning and preparing data from Inventory and Sales File.

## Tools
- Python
- Pandas
- JupyterLab

## Data Cleaning Techniques
- Handling missing values
- Standardizing inconsistent data
- Converting date formats
- Optimizing data types
- Filtering and validating records

## Datasets
This project uses two datasets for practicing data cleaning and preprocessing with Python and Pandas.
- Sales.csv
- Inventory.csv
Inside the documents you can find sales transactions records where I practiced better ways to handle missing values, Dates and Category standarization data.
